# Badminton Scoreboard

体育館のPC・iPadから使える、サーバーやデータベース不要のバドミントン用Webスコアボードです。

## 起動方法

`index.html` をブラウザで直接開くだけで使用できます。ローカルサーバーを使う場合は、プロジェクトのディレクトリで次を実行してください。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## GitHub Pagesで公開する方法

1. このファイル一式をGitHubリポジトリのデフォルトブランチへpushします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Build and deployment** のSourceで **Deploy from a branch** を選択します。
4. デフォルトブランチと `/ (root)` を選び、**Save** を押します。
5. 表示された公開URLへアクセスします。

## 主な機能

- 選手名・チーム名の編集（ダブルスの長い名前にも対応）
- 21点ラリーポイント、20点以降の2点差、30点上限の自動判定
- 3ゲームマッチ・2ゲーム先取と勝者表示
- 得点側へ自動で移るサーブ表示と、開始サーバー選択
- 直前の得点を取り消すUndo（ゲーム取得も取り消し可能）
- 現在のゲーム／試合全体のリセット
- フルスクリーン表示
- PC・iPad横画面向けレスポンシブデザイン

## テスト

得点ルールのテストはNode.jsで実行できます。

```bash
node test.js
```
